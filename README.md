# Telegram Bot on Render

This project runs a small Telegram bot using a webhook. It has `/start` and
`/help` commands.

## Deploy on Render

1. Push this project to a GitHub repository.
2. In Render, choose **New > Blueprint** and select the repository.
3. Render reads `render.yaml`. Set `TELEGRAM_BOT_TOKEN` to the token from
   `@BotFather`.
4. Create the service. Copy its public URL, for example
   `https://telegram-bot-xxxx.onrender.com`.
5. In the service's **Environment** settings, set `WEBHOOK_BASE_URL` to that
   public URL, then redeploy the service.

`WEBHOOK_SECRET` is generated by Render. Keep all environment variables out of
GitHub.

## Local run

For local testing, `WEBHOOK_BASE_URL` must be a public HTTPS URL that forwards
to your computer. Set the three required environment variables and run:

```powershell
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& ".\.venv\Scripts\python.exe" .\bot.py
```
